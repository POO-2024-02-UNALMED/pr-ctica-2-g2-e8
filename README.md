## Requirements

- Python 3.13.2
- pip

## Installation

1. Clone the repository:

```bash
    git clone {https://github.com/POO-2024-02-UNALMED/pr-ctica-2-g2-e8.git}
    cd {pr-ctica-2-g2-e8}
```

2. Create a virtual environment:

```bash
    python -m venv venv
    source venv/bin/activate
```

3. Install the requirements:

```bash
    pip install -r requirements.txt
```

## Usage

1. Run the application:

```bash
    ./run.sh
```
